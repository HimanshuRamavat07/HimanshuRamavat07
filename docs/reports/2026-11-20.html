Tencent releases open weights for multimodal flagship Hy4

Impact: 5/5Impact: 5 out of 5  |  Category: Models

What happened: Tencent posted Hy4, Hy4-FP8, and Hy4 base on Hugging Face, ModelScope, and GitCode. The language backbone uses 770B total parameters with 49B active per token. The model supports text, images, and video with a 1,048,576-token context window.

Research Worth Reading

CoReMem: Cost-Internalizing Memory for Successive Coding Tasks

Problem: Coding agents must write repository memory before the next task arrives, without knowing that task's shape or cost.

Key idea: CoReMem values memory segments by what they save on the next task and trains actors with provenance-gated credit on anchor locations and checks.

Why developers should care: On ChainSWE, the framework lifts resolve rate from 21.0% to 25.7% while cutting steps 17% and cache-aware tokens 11%.

Paper: arXiv:2611.17316

HEAMS: Holistic Evaluation of Agent Memory Systems

Problem: Agent memory benchmarks focus on task success and ignore security, privacy, and user control failures.

Key idea: HEAMS scores memory systems across performance, safety, privacy, and governance dimensions with unified scenarios.

Why developers should care: The work gives teams a checklist before shipping persistent agent memory in customer-facing products.

Paper: arXiv:2611.20144
