📚 Research Worth Reading

VERSE: Verified Self-Evolving Optimizer for Agent Harnesses

Problem: Harness optimizers usually fix their own procedures while editing executor prompts, tools, and control flow from failed trajectories alone.

Key idea: VERSE lets the optimizer replay failures, test draft harness edits, and evolve its own tools when execution verification is available.

Why developers should care: On held-out SWE-rebench and out-of-distribution coding tasks, VERSE raised accuracy to 42.3% and 37.7% versus 39.2% and 29.3% for the strongest baselines in the paper.

Paper: arXiv:2610.02616

Sentry: Learning to Recover from LLM Agent Failures at Test Time

Problem: Keeping failure playbooks always in context hurts agents, while runtime interventions that never learn repeat the same mistakes.

Key idea: Sentry retrieves external failure lessons only when a matching failure is detected, verifies recovery, and stores new lessons without loading the full playbook into context.

Why developers should care: Across WebShop, AppWorld, SWE-bench Lite, and Mind2Web Replay, Sentry beat the strongest runtime-intervention baseline on every benchmark, by 37% on average in the paper.

Paper: arXiv:2610.02994
