Cloudflare discloses cross-tenant GLM-5.3 Workers AI KV cache leak affecting 155 responses

Impact: ⭐⭐⭐⭐⭐Impact: 5 out of 5  |  Category: Security / Infrastructure

📚 Research Worth Reading

My Credentials, Please: Detecting Filesystem Capability Laundering in MCP Servers at Scale

Problem: Local MCP deployments often grant broad host filesystem access after a user approves a narrow tool contract.

Key idea: MCP-FSD catalogs servers, infers least-privilege boundaries, plants credential fixtures outside them, and dynamically tests whether arguments exfiltrate files anyway.

Why developers should care: The study finds 150 confirmed vulnerable servers among triaged registries, including two CVEs in Anthropic's Git MCP Server.

Paper: arXiv:2610.22301

Agentic AI Defense: Decode-Time Provenance Binding for MCP

Problem: Indirect prompt injection can hide instructions in tool outputs, including steganographic images that text scanners miss.

Key idea: Decode-time provenance binding labels untrusted decoded bytes, tracks taint in an MCP ledger, and blocks critical tool calls influenced by unauthenticated content.

Why developers should care: On a three-agent MCP testbed, the defense blocked 24 adaptive payloads after keyword and regex baselines still allowed 62.5% success.

Paper: arXiv:2610.31974
