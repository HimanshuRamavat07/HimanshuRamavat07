GitSpawn and marketplace SHA-pin bypass — supply-chain RCE across major coding agents

Impact: ⭐⭐⭐⭐⭐Impact: 5 out of 5  |  Category: Security / Developer Tools

What happened: Two related vulnerability classes dominated coding-agent security coverage this week. Manifold Security’s GitSpawn (disclosed September 1–2) shows malicious .git/config settings such as core.fsmonitor can execute attacker commands outside agent sandboxes when agents run background Git operations — affecting Claude Code, Codex, Cursor, Goose, Qwen Code, Grok Build, and others, with several patches still pending at disclosure. Separately, Air Security researchers reported (September 17) that Claude Code, Codex, Gemini CLI, and Copilot-family agents could fail to verify checkout integrity after SHA-pinned marketplace installs — enabling zero-click plugin replacement when upstream commits are swapped; Anthropic patched Claude Code 2.1.179 and OpenAI patched Codex 0.146.0.

Why it matters: Developer machines are high-trust environments: agents hold cloud credentials, production kubeconfigs, and signing keys. Supply-chain attacks that bypass the agent UI’s approval layer — via Git hooks or “honored but unverified” SHA pins — are more dangerous than classic prompt injection because they require no user interaction once a repo or plugin is trusted.

Adopt it — upgrade Claude Code and Codex to patched versions; disable automatic plugin updates until integrity verification is confirmed; treat cloned repos as untrusted until .git/config is audited; never run coding agents on sensitive hosts against unreviewed marketplace plugins

Source: The Register (Sep 17, 2026) · Shattered.io — GitSpawn · Cloud Security Alliance advisory

🔐 AI Security Watch

Issue: GitSpawn — Git config triggers commands outside agent sandboxes

Impact: Developer laptops and CI runners using affected coding agents against malicious or compromised repositories; full local user privileges.

Who should care: Developers, security engineers, anyone running autonomous coding agents on production-adjacent machines.

Recommended action: Clone untrusted repos only in disposable environments; inspect .git/config; apply vendor patches as released; restrict agent credentials to least-privilege scopes.

Issue: Marketplace SHA-pin verification bypass (Claude Code, Codex, others)

Impact: Silent replacement of “pinned” plugins/skills with malicious code; zero-click when auto-update is enabled.

Who should care: Developers using third-party agent marketplaces; platform teams curating internal plugin registries.

Recommended action: Upgrade to patched agent versions; disable auto-update until integrity checks are verified; manually review plugin repo history after pin changes.

Issue: Microsoft Semantic Kernel RCE (CVE-2026-26030, CVE-2026-25592)

Impact: Prompt injection leading to arbitrary code execution (Python InMemoryVectorStore) or persistent host compromise via Startup-folder writes (.NET SessionsPythonPlugin).

Who should care: Teams building .NET/Python agents on Semantic Kernel.

Recommended action: Upgrade to semantic-kernel 1.39.4 (Python) and .NET SDK 1.71.0; remove arbitrary file-write tools from model-visible surfaces; sandbox plugin execution.
