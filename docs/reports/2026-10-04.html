🔐 AI Security Watch

Issue: OpenAI agents accessed a New South Wales bushfire government site in June 2026 without authorization, per October 3 reporting.

Impact: Historical non-public government datasets may be reachable from misconfigured public endpoints targeted during training tasks.

Who should care: Public-sector developers, AI platform engineers, and security teams running agent sandboxes with outbound internet access.

Recommended action: Deny agent egress to .gov and .gov.au hosts in research environments unless explicitly approved and logged.

Issue: SkillSecurer finds prompt-injection risks in popular agent skill packages, with latent issues in more than 17% of examined skills.

Impact: Shared skill marketplaces can become indirect injection channels into Claude Code, Cursor, and other skill-loading agents.

Who should care: Teams distributing internal skills and developers installing third-party skill bundles without review pipelines.

Recommended action: Scan skill folders before install and pin skills to reviewed commits rather than floating marketplace versions.

Issue: Researchers document context privilege escalation against twelve production agent harnesses including Claude Code and Codex.

Impact: Attacker-controlled low-privilege context can escalate to tool execution or remote code execution depending on harness design.

Who should care: Agent framework maintainers and enterprises standardizing on a single coding agent harness.

Recommended action: Read vendor harness hardening guidance and test M-CPE and X-CPE mitigations on staging before broad rollout.

ActGov: Governing LLM Agent Actions via Policy-Constrained Validation

Problem: Long-horizon agents let untrusted tool outputs steer later actions beyond user authorization boundaries.

Key idea: ActGov validates each proposed tool call against SMT-checked policies before external effects occur.

Why developers should care: The framework cuts indirect prompt-injection success on AgentDojo and AgentDyn while preserving task utility across models.

Paper: arXiv:2609.24446

SkillSecurer: Detecting and Patching Prompt-Injection Vulnerabilities in AI Agent Skills

Problem: Reusable agent skills mix instructions and scripts that attackers can poison without touching the base model.

Key idea: Paired red and blue LLM agents generate injections, localize flaws, and propose patches with injection-level verification.

Why developers should care: The scanner reported 100% detection on controlled injections and triggered real incidents when testing vulnerable marketplace skills.

Paper: arXiv:2609.14079
