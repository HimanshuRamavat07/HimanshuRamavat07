📚 Research Worth Reading

ActGov: Governing LLM Agent Actions via Policy-Constrained Validation

Problem: Long-horizon agents let untrusted tool outputs expand authorization beyond user intent across dynamic workflows.

Key idea: ActGov builds SMT-verified policy sets offline, then validates each proposed tool call against task-scoped records before any external effect.

Why developers should care: Benchmarks on AgentDojo and AgentDyn show lower indirect prompt-injection success without relying on the LLM to spot malicious instructions.

Paper: arXiv:2609.24446

CONTINUITY: Security-Context Contracts for Composable LLM Agent Controls

Problem: Provenance, authorization, and execution controls often drop security context when agent actions cross component boundaries.

Key idea: CONTINUITY uses assume-guarantee contracts and signed transition receipts so every external effect links to a valid authorization witness.

Why developers should care: The reference verifier blocked harmful effects across 2,560 injected fault instances while completing benign tasks in the reported suite.

Paper: arXiv:2609.05269
