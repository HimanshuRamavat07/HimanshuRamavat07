📚 Research Worth Reading

My Credentials, Please: Detecting Filesystem Capability Laundering in MCP Servers at Scale

Problem: MCP tool approvals often grant entire host filesystem rights that exceed each tool’s declared schema and description.

Key idea: MCP-FSD catalogs servers, infers per-tool boundaries, plants credential fixtures, and dynamically tests exploitability across registries.

Why developers should care: The study triaged 21,097 servers and confirmed 150 vulnerable instances, including Git MCP CVEs.

Paper: arXiv:2610.22301

Agentic AI Defense: Decode-Time Provenance Binding for MCP

Problem: Text-only provenance labels fail when steganographic images launder instructions into agent control flow after tool decoding.

Key idea: The MCP layer HMAC-signs Untrusted labels at decode time and blocks critical sinks when lineage stays tainted.

Why developers should care: On 24 adaptive payloads the method reported 0% attack success versus 100% on an undefended pipeline.

Paper: arXiv:2610.31974
