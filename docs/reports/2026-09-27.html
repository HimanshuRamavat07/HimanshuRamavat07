📚 Research Worth Reading

Beyond Repeated Sampling: Learning Search Policies for LLM Reasoning

Problem: Repeated independent sampling yields near-duplicate reasoning traces on hard tasks.

Key idea: A small concept generator trained with reinforcement learning steers a frozen answer model through diverse hints.

Why developers should care: A cheap policy can raise pass rates for a larger model without retraining the answer generator.

Paper: arXiv:2609.26704

IterSynth: Rethinking Deep Search Agents via Role-Decoupled Iterative Synthesis

Problem: Single-policy ReAct agents mix planning and synthesis while long search histories add noise.

Key idea: Alternate Planner and Synthesizer roles with a summary state and role-specific reinforcement learning advantages.

Why developers should care: The authors report BrowseComp-style benchmark gains and zero-shot lifts on proprietary models via prompting.

Paper: arXiv:2609.29444

Dense Process Supervision for Search Agents via Fact Utility Estimation

Problem: Outcome-only rewards poorly credit intermediate search steps in question-answering agents.

Key idea: FactAgent clusters extracted facts and assigns dense step rewards from Bayesian utility estimates.

Why developers should care: The design fits multi-hop retrieval agents that maintain structured evidence stores.

Paper: arXiv:2609.00833
