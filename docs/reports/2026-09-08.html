📚 Research Worth Reading

CoSkill: Joint Reinforcement Learning of Reasoning and Meta-Skill Agents

Problem: Existing skill-library approaches decouple skill evolution from policy optimization or treat meta-skills as fixed workflows, limiting co-adaptation between reasoning agents and their skill libraries.

Key idea: CoSkill jointly trains a Reasoning Agent and a learnable Meta-Skill Agent over a hierarchical skill library, enabling end-to-end co-adaptation where task performance guides skill refinement. Achieves 98.4% on ALFWorld and 90.6% on WebShop (+3.5 and +6.2 pp over baselines).

Why developers should care: Provides a concrete architecture for agents that evolve their own tool/skill libraries during RL training — directly applicable to coding agents that accumulate procedural knowledge across sessions.

Paper: arXiv:2609.04865

Trace2Tower: Transition-Aware EigenTrace Induction of Multi-Level Skills

Problem: Current agent paradigms ignore temporal dependencies in execution traces, producing flat skill summaries that miss outcome-conditioned behavioral topology.

Key idea: Trace2Tower constructs a unified graph from step-level interactions, uses contrastive spectral decomposition to isolate success-aligned behavioral modes, and populates a dynamic skill tower of action templates, routines, and strategies. 87.31% success on ALFWorld with 10.35 steps and 0.26 invalid actions.

Why developers should care: Offers a principled method for distilling agent execution traces into reusable skill hierarchies — relevant for teams building agent memory and skill-retrieval systems.

Paper: arXiv:2609.05261

Latent Recurrent Thoughts: Recurrent Refinement with Frozen LLMs

Problem: Chain-of-thought reasoning in discrete token space commits errors at each step and requires trace supervision; reasoning in continuous latent space sidesteps this but lacks a computation mechanism.

Key idea: A small recurrent reasoner refines continuous latent thoughts over many steps while a frozen LLM decodes the final answer — decoupling computation depth from model size. Outperforms prior frozen-decoder methods on Countdown-4, Sudoku, HumanEval, MBPP, and StrategyQA.

Why developers should care: Shows that adding a lightweight recurrent module to a frozen backbone can improve reasoning without full fine-tuning — a potential pattern for enhancing deployed models without retraining.

Paper: arXiv:2609.01117
