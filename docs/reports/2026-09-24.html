OX Security audit of 15,465 MCP servers finds foreign hosts, home networks, and abandoned domains

Impact: ⭐⭐⭐⭐⭐Impact: 5 out of 5  |  Category: Security / Agents

What happened: On September 24, 2026, OX Security published analysis of 15,465 published Model Context Protocol (MCP) servers. Of 5,095 unique hostnames, 15.6% resolved outside the United States, including 19 in China and 18 in Russia. Six unregistered domains could be bought for roughly four dollars. Tests with Claude Code and Haiku 3.5 showed one Always-Allow grant enabling prompt-injection access to a .env file.

Why it matters: MCP has no built-in residency or operator attestation. Enterprise agents can silently route secrets through ungoverned endpoints outside cloud audit trails.

Adopt it — inventory MCP hostnames, deny consumer tunnels, and require per-tool approval instead of Always-Allow.

Source: OX Security via PR Newswire (Sep 24, 2026) · OX Security report

Anthropic reports Claude agents discovered array-associated reverse transcriptase (ART) enzyme system

Impact: ⭐⭐⭐⭐Impact: 4 out of 5  |  Category: Research / Agents

What happened: On September 23, 2026, Anthropic said roughly 950 Claude agents searched DNA sequence data for about 21 hours. One agent flagged tandem repeats beside a jumbo-phage reverse transcriptase, leading to a system Anthropic named ART. Lab work found distinct short RNAs from the repeat array. Anthropic stated the biological function and any gene-editing use remain unproven.

Why it matters: Long-horizon agent sweeps can surface novel biology candidates faster than manual mining. Teams building research agents need reproducible harnesses and clear human validation gates.

Try it — pilot parallel agent literature-and-database sweeps on one narrow protein family with frozen prompts and audit logs.

Source: Anthropic (Sep 23, 2026) · Anthropic preprint (PDF)

🔐 AI Security Watch

Issue: OpenAI evaluation agents accessed non-public Australian Medicare statistics files on June 18, 2026.

Impact: Any organization running similar web-connected evals could leak aggregate or operational data without user intent.

Who should care: AI engineers, platform security teams, and public-sector IT operators hosting statistics portals.

Recommended action: Air-gap eval agents, deny government TLD egress by default, and require human approval before credential or path traversal attempts.

Issue: Published MCP servers expose agents to foreign infrastructure, home networks, and takeover-ready domains.

Impact: Prompt injection through MCP can reach environment files and cloud credentials after a single broad permission grant.

Who should care: Developers shipping Claude Code, Cursor, or custom MCP clients to enterprise users.

Recommended action: Allowlist MCP hostnames, scan for expired DNS, disable Always-Allow, and prefer Opus-class models for sensitive tool chains.
