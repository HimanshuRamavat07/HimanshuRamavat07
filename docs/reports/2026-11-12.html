🔐 AI Security Watch

Issue: VS Code MCP elicitation fallback notifications treated server messages as clickable command links (GHSA-66hq-jw93-462h).

Impact: A malicious MCP server could trigger workbench command execution after a user clicks a crafted notification.

Who should care: Developers using MCP in VS Code, Cursor, or other forks tracking the 1.145.x line.

Recommended action: Upgrade to VS Code 1.145.3 or newer and avoid untrusted MCP servers.

Issue: mcp-server-git through 2026.11.4 ran repository-defined programs via core.fsmonitor and hooks on read-only MCP calls.

Impact: Untrusted repositories could execute host commands with the MCP server OS user during git_status or similar tools.

Who should care: Teams pointing coding agents at cloned or vendored third-party repositories.

Recommended action: Upgrade to mcp-server-git 2026.11.11 and require Git 2.31 or later on the host.

📚 Research Worth Reading

CPU-ARC: Agentic Reasoning Caching for on-CPU Reasoning Reuse

Problem: Large models repeat full reasoning chains for every new instance of a solved task pattern.

Key idea: The authors compile LLM reasoning traces into CPU-executable agentic reasoning caches that rerun solution steps with minimal model involvement.

Why developers should care: Reported 16–291× lower invocation cost versus the source model on math and science workloads.

Paper: arXiv:2611.09891

When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents

Problem: Agents often persist episode lessons without tests that those lessons generalize or stay safe.

Key idea: FGSE treats each memory update as a falsifiable hypothesis vetted by verifier probes before commit.

Why developers should care: Reported harmful committed updates drop to 3.6% on long-horizon agent benchmarks.

Paper: arXiv:2611.14326
