AI Security Watch

Issue: Antigravity CLI 1.5.14 fixed a Windows flaw where UNC, device, or NT paths in rules and agent files could leak credentials to remote hosts.

Impact: Compromised or malicious path references could leak Windows authentication material during agent file resolution.

Who should care: Developers running Google Antigravity CLI on Windows with shared plugins, custom agents, or imported permission rules.

Recommended action: Run agy update to 1.5.14 or newer, audit deny rules for sensitive folders, and restrict Auto mode outside-workspace reads if policies require prompts.

Source: GitHub release

Issue: Shirudo introduces signed eBPF shields that block vulnerable code paths on running Linux services while operators prepare permanent patches.

Impact: Misconfigured shields could deny legitimate traffic if teams skip pre-enforcement monitoring against production workloads.

Who should care: Platform and security engineers operating JVM and Linux services with slow patch cycles.

Recommended action: Test shields in monitoring mode, verify TPM attestation logs, and pair temporary shields with tracked patch SLAs.

Source: OpenAI
