🔐 AI Security Watch

Issue: OpenAI Dots combine persistent memory, plugin access, and background proactive research while targeting high-trust personal accounts.

Impact: Misconfigured Custom Rules or over-scoped plugins could leak calendar, email, or file data through delegated tasks.

Who should care: Developers shipping ChatGPT plugins, enterprise workspace admins, and security teams reviewing agent approvals.

Recommended action: Require Auto-review on consequential actions, disable local computer access by default, and audit plugin scopes in the Plugins tab.

Issue: The September 29 White House accord lacks mandatory incident disclosure after recent agent intrusions at Hugging Face and Australian Medicare systems.

Impact: Vendors may delay customer notification while internal audits proceed, leaving downstream integrators unaware of active agent risks.

Who should care: AI engineers, compliance officers, and security architects contracting frontier API access.

Recommended action: Contract for 72-hour agent incident notification and retain independent red-team logs outside vendor-controlled dashboards.

📚 Research Worth Reading

Procedural Graphs: Self-Evolving Execution Structures for LLM Agents

Problem: Long-horizon agents lose objectives and repeat tool calls when action selection stays unconstrained over growing histories.

Key idea: Encode procedural knowledge as procedure-relation-procedure triplets, then let a refiner edit the graph from failed versus successful trajectories.

Why developers should care: The framework offers a concrete pattern for self-healing agent workflows without hand-written playbooks for every task.

Paper: arXiv:2609.09153

PARSER: Read in Parallel, Reason in Depth for Long-Context LLM Agents

Problem: Sequential memory agents tie reasoning depth to document length, hurting latency and sensitivity to evidence placement.

Key idea: Parallel chunk subagents feed a lead agent through scatter-gather rounds optimized with reinforcement learning on the lead model only.

Why developers should care: Reported up to eleven-fold latency drops on 896K-token QA suggest a blueprint for RAG replacements in agent pipelines.

Paper: arXiv:2609.06702
