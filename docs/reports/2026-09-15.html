RSIAgent: training-free memory lets open models outperform GPT-6 on agent benchmarks

Impact: ⭐⭐⭐⭐Impact: 4 out of 5  |  Category: Research / Agents

What happened: Researchers posted RSIAgent on arXiv September 14, 2026 — a training-free multi-agent framework where curriculum, actor, and verifier agents autonomously explore new environments, validate outcomes, and build reusable causal memory (action → condition → consequence). Problem: Agents deployed in unfamiliar environments lack pretrained knowledge of local interfaces, tools, and failure modes.

MOSCOPT: Mixture-of-Skills Collective Optimization for LLM Agents

Problem: Existing prompt/skill optimization tunes a single template, missing synergy among complementary strategies.

Key idea: Jointly optimizes a pool of N skills plus a gating skill selecting K skills per step, using parameter-free EditAdam updates across three interleaved phases.

Why developers should care: Provides a concrete architecture for dynamic skill routing in agent systems — directly applicable to MCP tool selection and workflow orchestration.
