AWS ships HyperPod Global Inference Gateway for one cross-Region endpoint

Impact: 5/5Impact: 5 out of 5  |  Category: Infrastructure

What happened: On November 20, 2026, AWS announced SageMaker HyperPod Global Inference Gateway. One regional HTTPS endpoint scores member clusters on KV headroom, queue depth, Region proximity, and error rate, then forwards traffic over AWS PrivateLink.

Why it matters: Teams no longer need custom cross-Region load balancers to soak spare GPU capacity during peaks or survive a cluster failure.

Adopt it — Publish each HyperPod cluster with spec.globalRouting.enabled, then create a gateway with tuned routing weights.

Source: AWS ML Blog · Documentation

Obot patches critical MCP bypass when users rename themselves to anonymous

Impact: 4/5Impact: 4 out of 5  |  Category: Security

What happened: On November 20, 2026, Obot published advisory GHSA-cp2w-pc8v-r54p for releases 0.21.1 through 0.28.1. Signed-in users who renamed to anonymous could reach MCP servers they were never granted, with CVSS 9.6.

Why it matters: MCP governance layers that gate tools for agents become worthless when authorization keys off usernames instead of authentication state.

Adopt it — Upgrade Obot to 0.28.2 or later and block self-service username changes at the identity provider.

Source: GitHub Advisory · Release v0.28.2

AI Security Watch

Issue: Obot releases 0.21.1 through 0.28.1 let authenticated users rename to anonymous and invoke unauthorized MCP tools; GHSA-cp2w-pc8v-r54p rates the flaw critical.

Impact: Attackers with any normal account could reach MCP servers outside their grants, including admin-configured headers on those servers.

Who should care: Platform engineers running Obot gateways, MCP registries, or virtual MCP profiles for agent fleets.

Recommended action: Upgrade to Obot 0.28.2 or later. Verify usernames come only from SCIM or the identity provider.

Issue: MONAI Label 0.8.5 and earlier allow path traversal on datastore upload endpoints; GHSA-qc22-rmgc-vg94 lists no patched release yet.

Impact: Default deployments with authentication off permit arbitrary file writes; Amazon Threat Intelligence tied agent-led exploitation to root shell on a university host.

Who should care: ML platform teams hosting medical-imaging annotation servers and security staff watching autonomous scanning frameworks.

Recommended action: Enable MONAI Label authentication, block public exposure, and apply merged fix #1915 when maintainers ship a release.

Research Worth Reading

Learning dissipative chaotic dynamics with boundedness guarantees

Problem: Data-driven models of chaotic systems often drift into unbounded trajectories that break invariant statistics on long horizons.

Key idea: A modular dissipative projection layer learns an energy-like function and enforces dissipation as a hard constraint on neural emulators.

Why developers should care: The guarantee yields bounded long forecasts without arbitrary output caps, which matters for climate, turbulence, and control simulators.

Paper: PNAS (2026) · Code

Depth Pro 2: Sharp and Temporally Consistent Metric Monocular Depth

Problem: Monocular depth models usually trade sharp single-frame boundaries against stable multi-frame video depth.

Key idea: One scalable network trains on mixed image and video clips at native resolution with a lightweight focal-length estimator for streaming.

Why developers should care: Released weights span 24M to 872M parameters with Core ML exports, giving deployable depth for on-device spatial features.

Paper: arXiv:2611.26603
