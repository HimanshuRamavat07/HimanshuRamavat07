🔐 AI Security Watch

Issue: CVE-2026-125926 is server-side request forgery in AWS mcp-gateway-registry versions 1.0.3 through 1.34.0.

Impact: Authenticated users who may register MCP servers can aim the gateway at internal HTTP endpoints and sometimes read responses, including cloud metadata credentials.

Who should care: Platform engineers running MCP registries, AI gateway teams, and cloud security groups using attached instance roles.

Recommended action: Upgrade to mcp-gateway-registry 1.35.0, audit stored upstream addresses, review registration logs, and rotate cloud role credentials if exposure is possible.
