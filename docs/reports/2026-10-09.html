📚 Research Worth Reading

When Should Agents Think? Adaptive Reasoning via Cross-Turn Estimation

Problem: Agents often reason before every tool call, inflating token cost even when earlier reasoning still supports later actions.

Key idea: RACE uses likelihood drops on reference actions to decide when prior reasoning covers upcoming steps, then trains policies to skip redundant thinking.

Why developers should care: The paper reports up to 80% fewer reasoning tokens on WebShop with matched success. That pattern could cut agent inference bills if replicated in production stacks.

Paper: arXiv:2610.12061

DHCG: Dynamic Construction of Hierarchical Collaboration Graphs for LLM-Based Multi-Agent Reasoning

Problem: Fixed multi-agent topologies misalign dependencies and scale poorly as tasks evolve during execution.

Key idea: DHCG treats multi-agent setup as a partially observable decision process where a Planner module grows or stops a collaboration graph from live feedback.

Why developers should care: The framework reports double-digit benchmark gains over static multi-agent baselines on code, math, and domain reasoning suites.

Paper: arXiv:2610.07835
