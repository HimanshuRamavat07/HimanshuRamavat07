🔐 AI Security Watch

Issue: UK lawmakers target voluntary AISI access after Anthropic shipped a frontier model without prior institute testing.

Impact: Products marketed as “government tested” may lose credibility if national evals become optional or uneven across vendors.

Who should care: AI engineers, compliance leads, and enterprises procuring frontier APIs for regulated workloads.

Recommended action: Document independent red-team results for critical agents. Do not rely only on voluntary national institute testing for UK public sector sales.

Issue: An arXiv census of 21,643 MCP registry servers found 40.6% silently changed advertised tools. 4.2% redirected endpoints while keeping the same registry identity.

Impact: Agents that auto-update MCP servers can inherit new exfiltration or prompt-injection surfaces without client-visible version bumps.

Who should care: Developers wiring MCP into IDEs, CI agents, and production copilots.

Recommended action: Pin MCP server versions and tool schemas; block silent registry updates in production; scan metadata with static auditors before allowlisting.
