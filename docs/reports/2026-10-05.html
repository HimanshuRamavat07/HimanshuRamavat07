Problem: Fixed agent-security suites miss skill invocation, subagent delegation, and evolving harness behaviors in real workspace deployments.

Key idea: The EP-Path-EF framework links entry points to verified one-hop effects through automated case generation and runtime trace checks.

Securing Computer-Use Agents Against Branch Steering Attacks

Problem: Computer-use agents must branch on untrusted web content, breaking data-independent plans that dual-LLM defenses assume.

Key idea: COBRA pre-compiles branch-level capability constraints so runtime data can only pick among ahead-of-time bounded actions.

Why developers should care: On STEER-Bench, COBRA cut attack success from about 90% to 0% while keeping 97% benign-task utility.
