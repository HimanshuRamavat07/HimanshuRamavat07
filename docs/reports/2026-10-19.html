📚 Research Worth Reading

Probe-and-Resume: When and How to Evaluate Agent Execution

Problem: Terminal computer-use agents hide most environment state, so intermediate critics often cannot tell if a trajectory will succeed.

Key idea: Invoke a critic only at claimed completion, fork the machine state, and let the critic probe with read-write-exec before resuming failed runs.

Why developers should care: On Terminal-Bench 2.1, the authors report an 8.4 point success gain over conventional MCTS critics at under half Codex CLI cost.

Paper: arXiv:2610.21088

EvoProbe: Evaluation-Driven Benchmark Evolution for LLM Agents

Problem: Static agent benchmarks saturate and hide which reasoning phases actually fail during long trajectories.

Key idea: EvoProbe loops task generation, diagnostic trajectory scoring, and feedback-driven regeneration to evolve harder targeted tasks.

Why developers should care: Teams can grow internal eval suites from production failure modes instead of relying on stale public leaderboards.

Paper: arXiv:2610.19433
