📚 Research Worth Reading

CapLite: Prompt-Injection Defense for Small Language Model Agents without Model-Written Security Artifacts

Problem: Many agent defenses ask the same model to author policies or programs that gates later tool writes, which small open-weight models often get wrong.

Key idea: CapLite derives write policies from tool schemas and allows writes only when every destination argument appeared in the user's request.

Why developers should care: The authors report zero successful attacks across 13,935 attacked AgentDojo episodes with lower token use than CaMeL-style enforcement.

Paper: arXiv:2611.17115

SPILLWAY: Separating Target Admission from Sanitization to Defend Tool-Using Agents against Prompt Injection

Problem: Runtime defenses that re-call a language model on every step can still admit attacker-chosen payment or email targets hidden in untrusted tool output.

Key idea: SPILLWAY admits tool calls only when action targets come from typed read-only tool fields or fixed delegation rules, then sanitizes instruction-like spans deterministically.

Why developers should care: The paper reports no successful standard templated injections redirecting actions across three model backbones and seven task suites.

Paper: arXiv:2611.07222
