Switzerland confirms first AI-agent cyberattacks on critical infrastructure

Impact: 5/5Impact: 5 out of 5  |  Category: Security

What happened: On November 24, 2026, Switzerland's National Cyber Security Centre (NCSC) reported AI-assisted attacks on Swiss organizations. Attackers used agentic offensive frameworks that hunt weak passwords and known flaws on internet-facing systems.

Why it matters: The agency said freely reachable attack agents nearly doubled since October, compressing time for detection and response.

Adopt it — Patch internet-facing systems within twenty-four hours and require MFA on VPN, webmail, and remote admin paths.

Why it matters: Gemini 4 Carbon follows the same December schedule on the pricing page, so multi-model stacks need a unified cost refresh.

Pydantic releases Pax as the official Harness terminal coding agent

Impact: 4/5Impact: 4 out of 5  |  Category: Developer Tools / Agents

What happened: On November 25, 2026, Pydantic published Pax on PyPI as pydantic-ai-pax. The terminal agent builds on the Pydantic AI Harness Coder() capability. Teams can disable plugins, swap sandboxes, or load a custom Agent with --agent.

Why it matters: Pydantic plans a 1.0 Harness release in about one month, so the plugin API is approaching stability.

Try it — Run uvx pydantic-ai-pax on a trusted repo and compare token spend against an existing coding agent.

Source: Pydantic: Pax and Harness beta · Pax documentation

OpenAI rolls chat-optimized GPT-6.2 into the ChatGPT chat tab

Impact: 3/5Impact: 3 out of 5  |  Category: Models

Why it matters: OpenAI states Work and Codex models are unchanged by this chat update, separating subscriber chat upgrades from coding workloads.

Monitor it — Compare chat-tab answers against Work for code-heavy prompts before shifting default workflows.

Anthropic adds Install as app for Claude artifacts on Mac and Windows

Impact: 3/5Impact: 3 out of 5  |  Category: Developer Tools / Agents

AI Security Watch

Issue: Switzerland's NCSC confirmed AI-agent-assisted intrusions against companies and critical infrastructure operators, including successful compromises in multiple cases reported since November 24, 2026.

Impact: Internet-facing passwords, unpatched services, and MFA gaps become exploitable within minutes when attack agents iterate automatically.

Who should care: Platform engineers, SecOps teams, and SaaS builders exposing admin APIs, VPN portals, or webhooks to the public internet.

Recommended action: Minimize exposed systems, install critical patches within twenty-four hours, enforce MFA or passkeys on remote access, and run regular external penetration tests.

Research Worth Reading

MCP Tool Poisoning in Agentic AI Frameworks: A Cross-Framework Measurement Study

Problem: MCP feeds attacker-controlled tool metadata straight into model context without protocol-level validation.

Key idea: Researchers built a 9,720-cell matrix across twelve frameworks, eighteen models, and forty-five poisoning scenarios with confirmed exfiltration oracles.

Why developers should care: Overall attack success was 22.9%, with zero intentional framework defenses observed and wide variance across model providers.
