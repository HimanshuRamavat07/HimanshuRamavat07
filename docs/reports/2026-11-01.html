DeepSeek publishes dsh-superagent, a proactive GitHub coding agent prototype

Impact: ⭐⭐⭐⭐⭐Impact: 5 out of 5  |  Category: Agents / Developer Tools

🔐 AI Security Watch

Issue: CVE-2026-117569 (GHSA-qqg8-6hv5-w2xr) lets MCP scanner parameters in Kali-GPT reach subprocess.run with shell=True.

Impact: Prompt-injected agents could run shell commands as the MCP server user. GitHub lists no patched version yet.

Who should care: Developers wiring security-testing MCP servers into coding agents or CI pipelines.

Recommended action: Disconnect Kali-GPT MCP until a fix ships; pass tool args as lists without a shell in custom servers.

📚 Research Worth Reading

TokenEconomizer: Experience-Driven Black-Box Cost Control for Coding Agents

Problem: Coding agents burn tokens rediscovering repo facts and loading unused tools across long task sequences.

Key idea: An external plugin learns micro-skills from past sessions, prunes idle tools, and redirects stuck failure loops via a judge model.

Why developers should care: Reported SWE-Bench runs cut mean cost 18.4–30.9% with comparable Pass@1 on four of five agent–model pairs.

Paper: arXiv:2610.22732
