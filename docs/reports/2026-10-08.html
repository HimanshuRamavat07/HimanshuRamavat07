🔐 AI Security Watch

Issue: Langflow MCP stdio configuration allowed OS command injection before version 1.10.3 (GHSA-w794-rj3p-xv45, CVSS 9.9).

Impact: Attackers with MCP server settings or flow access could execute arbitrary commands as the Langflow process user, including via default auto-login on exposed instances.

Who should care: Teams self-hosting Langflow agent prototypes, platform engineers, and red teams testing MCP integrations.

Recommended action: Upgrade to Langflow 1.10.3 or later, disable `LANGFLOW_AUTO_LOGIN`, and restrict MCP package allowlists on multi-tenant hosts. GitHub advisory

Issue: MCP TypeScript SDK OAuth clients could send refresh tokens or client secrets to attacker-chosen authorization servers (CVE-2026-104850 / GHSA-6qxp-vccf-f47h).

Impact: HTTP MCP clients using bundled OAuth providers may leak long-lived credentials when connecting to untrusted servers without issuer binding.

Who should care: Developers shipping MCP clients, IDE plugins, and agent gateways that store OAuth tokens for third-party tools.

Recommended action: Upgrade to `@modelcontextprotocol/sdk` 1.31.0+ or `@modelcontextprotocol/client` 2.2.0+, set `expectedIssuer`, rotate secrets if exposure is possible. GitHub advisory

Issue: Researcher Syed Anas Mohiuddin documented cross-agent trust failures and SSRF in Google MCP Toolbox for Databases, alongside separate Rapid7 MCP flaws.

Impact: Malicious content routed between agents via MCP, A2A, or similar protocols can trigger unauthorized requests or delegated harmful actions inside trusted networks.

Who should care: Security architects designing multi-agent internal networks, MCP server operators, and compliance teams reviewing agent blast radius.

Recommended action: Treat all tool inputs as hostile, enforce redirect and IP validation on MCP HTTP clients, and segment agent credentials per task. Ars Technica (Oct 5, 2026)

📚 Research Worth Reading

Sentry: Learning to Recover from LLM Agent Failures at Test Time

Problem: Agents fail mid-task on bad tool calls or loops, yet storing every failure lesson inside context often hurts performance when conditions differ.

Key idea: Sentry keeps a failure playbook outside the agent context, retrieves lessons only when a failure is detected, verifies recovery without task rewards, and stores lessons conditionally.

Why developers should care: Reported benchmarks show large gains over runtime-only repair baselines, offering a concrete pattern for production agent reliability layers.

Paper: arXiv:2610.02994

VERSE: Verified Self-Evolving Optimizer for Agent Harnesses

Problem: Harness optimizers improve agent prompts and tools but rarely improve their own diagnosis and verification procedures.

Key idea: VERSE lets an optimizer replay failures, test draft harness edits, and co-evolve executor and optimizer tooling under fixed model weights with execution-based checks.

Why developers should care: Held-out coding benchmarks report higher accuracy than strong baselines, pointing toward automated harness tuning for coding agents.

Paper: arXiv:2610.02616
