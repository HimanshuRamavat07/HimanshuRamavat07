📚 Research Worth Reading

Grow the Harness, Not the Context: From Strategy-Free Scaffolds to Reusable Specialist Agents

Problem: Tool-calling agents repeat the same control logic in context, inflating tokens and cost on related tasks.

Key idea: Growing Harness learns executable control code from failures while keeping the large language model for semantic steps only.

Why developers should care: Reported runs cut inference cost up to 98.6% and keep WebArena-Verified success near 45% even with 4B models.

Paper: arXiv:2609.26760

Self-Healing Harness for Runtime Oversight of Agent Self-Modification

Problem: Agents that rewrite their own instructions can improve one task while silently breaking previously working cases.

Key idea: An external gate admits self-edits only after replay or forward trials show gain without regression on protected cases.

Why developers should care: Across 16 matched runs, the gate rejected 383 proposals where 55% fixed the trigger but harmed another case.

Paper: arXiv:2609.24130
