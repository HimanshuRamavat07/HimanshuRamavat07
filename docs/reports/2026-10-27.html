🔐 AI Security Watch

Issue: GPT-6.1 Terra meets OpenAI's Critical cybersecurity Preparedness threshold and ships with GPT-6 Astra-grade protections.

Impact: Offensive coding and computer-use features become cheaper to invoke at scale, widening abuse surface for unattended agents.

Who should care: Developers shipping browser or desktop agents, platform teams enabling Copilot cloud agents, and security reviewers.

Recommended action: Require human approval for destructive tool calls, log Terra sessions, and restrict egress on agent hosts.

Issue: OpenAI reports strong prompt-injection resistance on Terra in internal tests, while the model still reaches Critical cyber capability.

Impact: Indirect injection via documents and tool outputs remains the likely failure mode for production agents.

Who should care: AI engineers wiring MCP tools, RAG pipelines, and email-to-agent workflows.

Recommended action: Enforce execution-boundary checks on tool args and outputs rather than relying on model refusals alone.

📚 Research Worth Reading

GatewayBench: Unified Capability and Security Evaluation Platform for MCP Gateways

Problem: MCP gateways shape which tools agents see, but no benchmark compared gateway designs at scale.

Key idea: GatewayBench runs 524 tasks with up to 11,118 real tools injected to test flat versus hierarchical discovery gateways.

Why developers should care: Gateway choice materially shifts completion rates, token cost, and exposure to malicious tools.

Paper: arXiv 2610.23449

APEX: Active Protection at Execution Boundaries for LLM Agents

Problem: Indirect prompt injection propagates through tools, MCP servers, and skills faster than pattern-based filters.

Key idea: APEX authorizes external effects only when runtime state matches task-endorsed information at execution boundaries.

Why developers should care: The design targets a stable enforcement point instead of chasing every injection carrier format.

Paper: arXiv 2610.06966
